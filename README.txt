Publish with GitHub Pages:
  1. Create a public GitHub repository for this site.
  2. Upload index.html, style.css, assets/logo.svg and fonts/Equinor-Bold.woff2, retaining the folder structure.
  3. Go to Settings > Pages > Deploy from a branch, select main and /(root).
  4. To connect your domain, use Settings > Pages > Custom domain and follow the current GitHub Pages DNS instructions in GoDaddy.
  5. Preserve existing MX, SPF, DKIM and other email records in GoDaddy.
  6. Enable Enforce HTTPS when it becomes available.

IMPORTANT: Ensure the Equinor font licence permits public web embedding, and you have permission to use it on your company's website.
